# Argus · W0 决策日志

> **目的**：记录 W0（PRD + 架构阶段）所有关键决策点，便于 W1-W4 启动时回看。
> **格式**：每个决策列「选项 / 选定 / 理由 / 备选 / 触发再评估条件」。
> **最后更新**：2026-09-18

---

## 1. 项目命名

| 字段 | 内容 |
|---|---|
| 选定 | **Argus** |
| 备选 | Synapse（突触）/ Pulse（脉搏）/ scholairum / **你来定** |
| 理由 | 希腊神话 Argus Panoptes 百眼巨人，象征「多视角洞察，不遗漏」最贴合 multi-agent 多视角主题 |
| 决定时刻 | 第一轮「项目名」AskUserQuestion |
| 再评估 | 永不（除非品牌改名） |

## 2. 研究场景

| 字段 | 内容 |
|---|---|
| 选定 | **新闻 / 舆情 / 趋势追踪** |
| 用户提议 | 个人研究助手（最初版本，未明确方向） |
| 排除 | 论文 / 报告（用户中途要求「不涉及论文，研究其他方向」） |
| 备选 | 竞品 / 公司调研 / 技术选型 / 求职情报 / 跨领域 |
| 再评估 | W2 demo 后看效果，如舆情方向表现不佳可换其他场景 |

## 3. 数据源

| 字段 | 内容 |
|---|---|
| 选定 | **用户上传文档 + 网页抓取（含视频转写 / OCR）** |
| 排除 | 实时网络搜索作为主源（成本高、稳定性差） |
| 备选 | 仅上传（demo 数据弱）/ 实时搜索 + 上传（成本 + 复杂度） |
| 再评估 | W2 RAG 检索质量不达标时，考虑加重实时搜索 |

## 4. 抓取深度

| 字段 | 内容 |
|---|---|
| 选定 | **重量级（多模态：含 OCR + 视频 / 音频转写）** |
| 备选 | 轻量（仅文章 / RSS）/ 中等（含表格） |
| 再评估 | 转写成本 > 预期 2x 时，降级到中等 |

## 5. 多模态输入

## 21. 用户主动排除的项

| 排除项 | 排除原因 |
|---|---|
| **论文 / 学术研究** | 用户明确说「不涉及论文，研究其他方向」 |
| **LlamaIndex** | 与 LangGraph 1.x 抽象重叠 |
| **实时流式推送**（WebSocket） | SSE 单向足够 |
| **移动端 App** | 仅 Web 响应式 |
| **模型微调** | demo 阶段不需要 |
| **企业级 SSO / RBAC** | 个人 / 小团队场景 |
| **第三方 benchmark（HotpotQA）** | stretch 阶段 |
| **Webhook / Slack 推送** | MVP 不需要 |
